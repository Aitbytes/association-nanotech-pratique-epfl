## Pourquoi ce projet existe

Les étudiants en nanotechnologie et microtechnique à l'EPFL ont accès à l'une des meilleures infrastructures de microfabrication au monde (le CMi), mais **peu d'opportunités concrètes** de l'utiliser pour des projets étudiants autonomes.

Les associations existantes (EPFL Photonics Chapter, Dynamic, QET) excellent dans l'organisation d'événements et de networking, mais **aucune ne fait de fabrication physique**.

Les rares initiatives comparables dans le monde (SEMMI à Chicago, SiliconJackets à Georgia Tech) se limitent à un domaine (circuits numériques ou MEMS) et n'atteignent pas le niveau d'intégration visé ici.

**Cette association comble ce vide.**

## Le Projet Phare : Biocapteur Photonique Intégré

### C'est quoi ?

Une plateforme lab-on-a-chip photonique monolithiquement intégrée sur SOI :

- **Microrésonateur en anneau (MRR)** comme biocapteur
- **Spectromètre Fourier intégré** pour la lecture optique
- **Canaux microfluidiques** pour l'écoulement des échantillons

### Pourquoi c'estunique ?

- **Première mondiale** : aucun système intégré MRR + spectromètre Fourier sur une même plateforme
- **Single-chip** : plus besoin d'analyseur optique externe
- **Applications** : diagnostic médical point-of-care (POCT)

### Timeline

| Phase                  | Durée          |
| ---------------------- | -------------- |
| Design + simulation    | 2-3 mois       |
| 1ère fabrication       | 1-2 mois       |
| Caractérisation        | 1-2 mois       |
| Fonctionnalisation bio | 3-4 mois       |
| Prototype fonctionnel  | **12-14 mois** |
